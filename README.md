# RakWebDrop

เว็บส่วนตัวสำหรับรับและดูข้อความจากบอต Discord หรือ JSON จากระบบอื่น

## เริ่มใช้งาน

ต้องติดตั้ง Node.js ก่อน (แนะนำรุ่น LTS) จากนั้นเปิด PowerShell ในโฟลเดอร์นี้ แล้วรัน:

```powershell
node start.js
```

คำสั่งนี้เปิดทั้งเว็บและบอตในหน้าต่างเดียว เมื่อเห็นข้อความว่าเชื่อมต่อ Discord สำเร็จ ให้เปิด <http://localhost:4173> ในเบราว์เซอร์ และค้างหน้าต่าง PowerShell ไว้ระหว่างใช้งาน หากปิดหน้าต่างหรือคอมพิวเตอร์พัก/ปิด บอตจะหยุดรับข้อความ

## เปิด RakWebDrop บนมือถือ

คอมพิวเตอร์และมือถือจะต้องเชื่อมต่อ Wi-Fi เครือข่ายเดียวกัน จากคอมพิวเตอร์เปิด PowerShell แล้วพิมพ์ `ipconfig` จากนั้นหา `IPv4 Address` ของ Wi-Fi เช่น `192.168.1.25` แล้วเปิด `http://192.168.1.25:4173` บนมือถือ โดยแทนที่ตัวอย่างด้วย IP ของคอมพิวเตอร์ หาก Windows Firewall ถาม ให้เลือกอนุญาตเฉพาะเครือข่ายส่วนตัวที่เชื่อถือได้

RakWebDrop ไม่มีหน้าล็อกอิน อุปกรณ์อื่นบน Wi-Fi เดียวกันอาจเปิดดูข้อมูลได้ จึงไม่ควรเปิดใช้บน Wi-Fi สาธารณะหรือเปิดพอร์ตจากเราเตอร์สู่อินเทอร์เน็ต

## ลองรับข้อมูล

กด **ส่งข้อมูลทดสอบ** บนหน้าเว็บเพื่อสร้างรายการตัวอย่าง หรือกด **คัดลอก Webhook URL** แล้วตั้งให้บอต/ระบบของคุณส่ง HTTP `POST` แบบ JSON มายัง URL นั้น ตัวอย่าง payload:

```json
{
  "event": "message.created",
  "author": { "username": "bluebird" },
  "channel": { "name": "general" },
  "content": "สวัสดีจาก Discord"
}
```

ระบบตอบ `202 Accepted` เมื่อบันทึกสำเร็จ และปฏิเสธ JSON ที่ผิดรูปแบบหรือมีขนาดเกิน 256 KB

## เชื่อมบอต Discord

มีตัวเชื่อมบอตให้ใน `discord-bot.js` ใช้ Node.js 22 ขึ้นไปและไม่ต้องติดตั้งแพ็กเกจเพิ่ม บอตจะส่งข้อความใหม่และอัปเดตจากเซิร์ฟเวอร์ Discord ที่เข้าถึงได้มาแสดงใน RakWebDrop

1. ไปที่ [Discord Developer Portal](https://discord.com/developers/applications) แล้วสร้าง Application และเพิ่ม Bot.
2. ในหน้า **Bot** เปิด **Message Content Intent** ในส่วน Privileged Gateway Intents.
3. เชิญบอตเข้าเซิร์ฟเวอร์ของคุณผ่าน OAuth2 URL Generator โดยเลือก scope `bot` และให้สิทธิ์ **View Channels** กับ **Read Message History** เฉพาะช่องที่ต้องการให้บอตอ่าน.
4. คัดลอกโทเคนบอต แล้วสร้างไฟล์ `.env` จาก `.env.example` จากนั้นใส่โทเคนใน `DISCORD_BOT_TOKEN`.
5. เปิด PowerShell ในโฟลเดอร์นี้แล้วรัน `node start.js`.

หากต้องการดึงข้อความ AA Script Hook ที่พลาดไป ให้เปิด PowerShell อีกหน้าต่างในโฟลเดอร์นี้ขณะที่ `node start.js` ยังทำงาน แล้วรัน `node backfill.js` คำสั่งนี้จะตรวจย้อนหลังไม่เกิน 100 ข้อความต่อช่องที่เคยรับข้อมูลจาก AA Script Hook และนำเข้าเฉพาะข้อความจากบอตนั้น ต้องมีสิทธิ์ **View Channels** และ **Read Message History** ข้อความที่ถูกลบไปแล้วหรือเก่ากว่า 100 ข้อความล่าสุดจะไม่ถูกดึงด้วยคำสั่งนี้

อย่าแชร์โทเคนบอตหรือใส่ลงในแชต/เว็บไซต์สาธารณะ หากโทเคนรั่ว ให้สร้างโทเคนใหม่ใน Developer Portal ข้อความจะเริ่มเข้าหลังบอตออนไลน์ และหน้าเว็บอัปเดตทุก 5 วินาที

Discord ต้องให้บอตเชื่อมต่อ Gateway เพื่อรับข้อความในเซิร์ฟเวอร์; webhook ที่สร้างจากหน้า Discord ใช้ส่งข้อความเข้า Discord ไม่ได้ทำหน้าที่อ่านข้อความในช่อง [ดูความแตกต่างระหว่าง Webhooks กับ Bots](https://discord.com/safety/using-webhooks-and-embeds).

## เปิดใช้งานจากอินเทอร์เน็ตโดยไม่เปิดคอมที่บ้าน

การเปิด `index.html` โดยตรงจากโฟลเดอร์ (ที่อยู่ขึ้นต้นด้วย `file:///`) จะไม่เชื่อมต่อกับข้อมูล ต้องเปิดผ่าน `http://localhost:4173` ตอนรันเว็บในเครื่อง หรือใช้ URL ของผู้ให้บริการโฮสต์หลังนำขึ้นระบบแล้ว

โปรเจกต์เตรียมสำหรับ Railway ไว้แล้ว โดยเว็บและบอตทำงานด้วย `node start.js` ในบริการเดียว ใช้ Node.js 22 และเก็บไฟล์ฐานข้อมูลไว้ใน volume แบบถาวร

1. อัปโหลดโปรเจกต์นี้ไปยัง GitHub repository ส่วนตัว โดยไม่อัปโหลด `.env` หรือโฟลเดอร์ `data/`.
2. สร้างโปรเจกต์ใน [Railway](https://railway.com/) แล้วเชื่อม GitHub repository นี้.
3. ใน Variables ของบริการ เพิ่ม `DISCORD_BOT_TOKEN`, `DASHBOARD_PASSWORD`, `SESSION_SECRET` และ `DATA_DIR=/data`.
   - ใช้โทเคน Discord ใหม่ที่ยังไม่เคยเปิดเผย และตั้งรหัสผ่านหน้าเว็บที่ยาวและไม่ซ้ำกับที่อื่น.
   - ตั้ง `SESSION_SECRET` เป็นค่าสุ่มยาว ๆ; ห้ามนำค่าโทเคนหรือรหัสผ่านมาใช้ซ้ำ.
4. ใน Settings → Volumes สร้าง volume และ mount path เป็น `/data` เพื่อไม่ให้รายการหายเมื่อมีการ deploy ใหม่.
5. Deploy แล้วไปที่ Settings → Networking → Public Networking → Generate Domain จากนั้นเปิดโดเมน HTTPS ที่ได้และเข้าสู่ระบบด้วย `DASHBOARD_PASSWORD`.
6. เชิญบอตตัวเดิมหรือบอตใหม่เข้าเซิร์ฟเวอร์ Discord และให้สิทธิ์อ่านเฉพาะช่องที่ต้องการ บอตจะเชื่อมต่อเองหลัง deploy.

**ค่าใช้จ่าย:** Railway Free มีเครดิตทรัพยากรจำกัดและบริการจะพักเมื่อไม่มีการใช้งาน จึงไม่เหมาะกับบอตที่ต้องออนไลน์ตลอด แผน Hobby เริ่มที่ US$5 ต่อเดือน และคิดเพิ่มได้หากใช้ทรัพยากรเกินเครดิตของแผน ตรวจสอบยอดใน Railway ก่อนยืนยันสมัคร

เว็บไซต์สาธารณะจะเปิดรับจากอินเทอร์เน็ต แต่หน้า Dashboard ต้องล็อกอิน ส่วน URL webhook และ Discord bot token เป็นความลับ ห้ามแชร์หรือฝังไว้ใน GitHub
